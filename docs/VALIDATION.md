## 首版模型与未训练基线：通过晋级

另一组未见场景种子 20000–20029，三任务共 90 对。未训练基线为零权重的 Compact 模型，候选顺序按种子重排。

| 指标 | 未训练基线 | 第一轮 Compact |
|---|---:|---:|
| 成功 | 1/90 | 90/90 |
| 碰撞 | 0 | 0 |
| 失抓 | 14 | 0 |
| 动作拒绝 | 70 | 0 |

成功率提升 98.89 个百分点，配对 bootstrap 95% 区间 [96.67, 100] 个百分点。三个任务各 30/30 完成，第一轮模型通过全部门槛，并登记为本机 `champion.json`。这个成绩仅证明小范围结构化状态／固定技能协议中的学习效果。[机器可读报告](results/paired-baseline.json)

## 第二轮版本的独立任务评测：拒绝晋级

场景种子 10000–10029，每任务 30 个配对，共 90 对；相同控制器、候选和 20 步预算。

| 指标 | 第一轮模型 | 第二轮候选 |
|---|---:|---:|

| 碰撞 / 失抓 / 拒绝 | 0 / 0 / 0 | 0 / 0 / 0 |

配对提升 -100 个百分点，bootstrap 95% 区间 [-100, -100] 个百分点。候选违反成功率及旧任务退化门槛，**未晋级**。

[机器可读失败报告](results/paired-regression.json)

主要失败模式：到达物体上方后选择抓取，没有先下降；空抓后重复抓取直到停滞。这个结果说明一步标签准确率不足以替代任务级成功率，失败记录必须保留。后续实验应在开发场景做闭环诊断和状态纠正；本组发布场景已被读取，不再用它调参后声称独立验证。

## RSI-Jev 真实 GPU 微调

- 模型：`shgao/rsi-jev-v1.0-qwen3.5-0.8b`。
- HF revision：`f9248caceb89caf2e6c968ea33bf0d6eb7f957b0`。
- 第一轮语料的 train/dev 分组，决策头训练 20 步，batch size 2，lr 1e-4。
- 开发集监督损失：2.363616 → 2.087593。
- 开发集动作标签准确率：6.25% → 20.3125%。
- 缓存加载后的训练、开发集评测与重载验证共约 95 秒；首次权重下载另计。
- 检查点保存后，以一个开发样本验证预测数值重载一致，`atol=rtol=1e-5`。

这是训练接口和监控的真实 GPU 冒烟验证，尚未证明该 RSI 模型能完成机器人任务。没有宣称 2B/4B 训练效果，也未沿用父模型校准。

微调检查点随后通过上游 `Decider` 接入真实仿真：一个搬运场景、8 步预算，调用和执行链路正常，任务未完成。这条失败轨迹也保留在本机记录中。[GPU 训练摘要](results/rsi-smoke.json)
